Technical FAQ

Can I run CLI flags silently without launching UI windows?

Yes. Every CLI flag runs straight against Windows CCD and exits cleanly, or passes --tray to keep background hotkeys active.

What happens when I pass --lang id or --lang en?

The flag overrides CLI output text for that single command without altering your saved UI language setting.
